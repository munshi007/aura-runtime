# Support and versioning

Aura follows Semantic Versioning expressed with PEP 440 prerelease identifiers. The current
`0.x` alpha may contain breaking changes between minor releases.

Only documented imports from `aura_runtime`, documented CLI commands, AuraSpec syntax, and
documented MCP tools are public interfaces. Other modules and evidence schemas are
experimental unless stated otherwise. Deprecations should remain for at least two alpha
minor releases when practical; security fixes may require faster change.

Use GitHub issues for reproducible bugs and feature discussions. Use the private route in
[SECURITY.md](SECURITY.md) for vulnerabilities. Community support is best effort.
